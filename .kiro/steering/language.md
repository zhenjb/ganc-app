# Quy tắc ngôn ngữ

## Phân tích & tài liệu → Tiếng Việt
- **Mọi phân tích, giải thích, nhận xét của AI** (trong chat, trong file `.md`, trong specs, design docs, requirements, steering files): **luôn luôn bằng tiếng Việt**.
- Không có ngoại lệ — dù đang trả lời câu hỏi, phân tích code, đề xuất giải pháp, hay viết tài liệu, tất cả prose/phân tích đều phải là tiếng Việt.
- Phạm vi áp dụng: tất cả file dưới `.kiro/specs/`, `.kiro/steering/`, `task/`, và mọi câu trả lời/phân tích trong conversation.

## Code comments → English
- **Code comments** (inline comments, JSDoc, TODO/FIXME, test descriptions): viết hoàn toàn bằng **English**.
- Không dùng tiếng Việt trong bất kỳ comment nào nằm trong file code (`.ts`, `.tsx`, `.scss`, `.css`, `.json`, v.v.).

## UI strings → English
- User-visible UI strings (labels, buttons, messages hiển thị cho người dùng) vẫn giữ nguyên **English** theo product rules.
